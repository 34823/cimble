# Contributing

Bug reports, ideas and pull requests are welcome.

- **Bug** — open an [issue](https://github.com/34823/cimble/issues/new/choose) with the command, its output, OS, Python and cimble versions.
- **Idea or question** — [Discussions](https://github.com/34823/cimble/discussions).
- **Pull request** — keep it small and focused; layout and rules are in [docs/DEVELOPING.md](docs/DEVELOPING.md). Before sending run:

```
python3 -m pytest
```

Do not put real project memory into issues or commits: examples must be fictitious.
